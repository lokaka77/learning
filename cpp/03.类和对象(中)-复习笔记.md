## 1. 类的默认成员函数

用户没有显式实现时，编译器可能自动生成的成员函数称为默认成员函数。

本章重点掌握以下 6 个：

| 默认成员函数 | 作用 |
| --- | --- |
| 构造函数 | 对象创建时初始化 |
| 析构函数 | 对象销毁时清理资源 |
| 拷贝构造函数 | 用一个已有对象初始化新对象 |
| 赋值运算符重载 | 两个已有对象之间进行赋值 |
| 取地址运算符重载 | 获取普通对象地址 |
| `const` 取地址运算符重载 | 获取 `const` 对象地址 |

其中前 4 个最重要。C++11 还会增加移动构造和移动赋值，后续章节再学习。

学习每个默认成员函数时，重点回答两个问题：

1. 自己不写时，编译器生成的行为是什么，是否满足需求？
2. 编译器生成的行为不满足需求时，应该如何自己实现？

## 2. 构造函数

构造函数是特殊的成员函数。它主要负责对象创建后的初始化，而不是开辟对象空间。

特点：

1. 函数名与类名相同。
2. 无返回值，也不需要写 `void`。
3. 对象实例化时自动调用。
4. 可以重载。
5. 没有显式定义构造函数时，编译器会生成无参默认构造函数；用户一旦显式定义，编译器就不再生成。
6. 不传实参就能调用的构造称为默认构造，包括：
   - 无参构造函数
   - 全缺省构造函数
   - 编译器自动生成的构造函数
7. 编译器生成的构造函数：
   - 对内置类型成员不保证初始化。
   - 对自定义类型成员会调用其默认构造函数。
   - 如果自定义类型成员没有默认构造函数，编译会报错。

C++ 类型分类：

| 类型 | 说明 | 例子 |
| --- | --- | --- |
| 内置类型 | 语言原生类型 | `int`、`char`、`double`、指针 |
| 自定义类型 | 使用 `class`、`struct` 定义的类型 | `Date`、`Stack` |

### 2.1 Date 的构造函数

```cpp
#include<iostream>
using namespace std;
class Date
{
public:
    // 1.无参构造函数
    Date()
    {
        _year = 1;
        _month = 1;
        _day = 1;
    }
    // 2.带参构造函数
    Date(int year, int month, int day)
    {
        _year = year;
        _month = month;
        _day = day;
    }
    // 3.全缺省构造函数
    /*Date(int year = 1, int month = 1, int day = 1)
    {
        _year = year;
        _month = month;
        _day = day;
    }*/
    void Print()
    {
        cout << _year << "/" << _month << "/" << _day << endl;
    }
private:
    int _year;
    int _month;
    int _day;
};
int main()
{
    // 如果留下三个构造中的第二个带参构造，第一个和第三个注释掉
    // 编译报错：error C2512: "Date": 没有合适的默认构造函数可用
    Date d1;             // 调用默认构造函数
    Date d2(2025, 1, 1); // 调用带参的构造函数
    // 注意：如果通过无参构造函数创建对象时，对象后面不用跟括号，否则编译器无法
    // 区分这里是函数声明还是实例化对象
    // warning C4930: "Date d3(void)": 未调用原型函数(是否是有意用变量定义的?)
    Date d3();
    d1.Print();
    d2.Print();
    return 0;
}
```

**讲解**：

- `Date d1;` 调用默认构造。
- `Date d2(2025, 1, 1);` 调用带参构造。
- `Date d3();` 会被解释为函数声明，而不是创建对象，这是经典易错点。
- 如果只保留 `Date(int year, int month, int day)`，那么 `Date d1;` 会因为找不到默认构造而编译失败。
- 无参构造和全缺省构造不能同时存在，因为 `Date d1;` 会产生调用歧义。

### 2.2 Stack 与 MyQueue 的默认构造

```cpp
#include<iostream>
using namespace std;
typedef int STDataType;
class Stack
{
public:
    Stack(int n = 4)
    {
        _a = (STDataType*)malloc(sizeof(STDataType) * n);
        if (nullptr == _a)
        {
            perror("malloc申请空间失败");
            return;
        }
        _capacity = n;
        _top = 0;
    }
    // ...
private:
    STDataType* _a;
    size_t _capacity;
    size_t _top;
};
// 两个Stack实现队列
class MyQueue
{
public:
    //编译器默认生成MyQueue的构造函数调用了Stack的构造，完成了两个成员的初始化
private:
    Stack pushst;
    Stack popst;
};
int main()
{
    MyQueue mq;
    return 0;
}
```

**讲解**：

- `Stack(int n = 4)` 是全缺省构造，也是默认构造。
- `MyQueue mq;` 会调用编译器生成的默认构造。
- 编译器生成的默认构造会依次初始化自定义类型成员 `pushst` 和 `popst`。
- 因为 `Stack` 有默认构造，所以 `MyQueue` 不需要显式写构造函数。

## 3. 析构函数

析构函数用于对象销毁时清理资源。

特点：

1. 函数名为 `~类名`。
2. 无参数、无返回值。
3. 一个类只能有一个析构函数。
4. 对象生命周期结束时自动调用。
5. 编译器生成的析构函数：
   - 对内置类型成员不做处理。
   - 对自定义类型成员调用其析构函数。
6. 即使显式编写析构函数，自定义类型成员仍会自动调用自己的析构函数。
7. 没有申请资源时可以不写析构函数；申请了资源则必须写，否则资源泄漏。
8. 同一局部作用域内，后定义的对象先析构。

### 3.1 Stack 与 MyQueue 的析构

```cpp
#include<iostream>
using namespace std;
typedef int STDataType;
class Stack
{
public:
    Stack(int n = 4)
    {
        _a = (STDataType*)malloc(sizeof(STDataType) * n);
        if (nullptr == _a)
        {
            perror("malloc申请空间失败");
            return;
        }
        _capacity = n;
        _top = 0;
    }
    ~Stack()
    {
        cout << "~Stack()" << endl;
        free(_a);
        _a = nullptr;
        _top = _capacity = 0;
    }
private:
    STDataType* _a;
    size_t _capacity;
    size_t _top;
};
// 两个Stack实现队列
class MyQueue
{
public:

    // 显示写析构，也会自动调用Stack的析构
    /*~MyQueue()
     {}*/
private:
    Stack pushst;
    Stack popst;
};
int main()
{
    Stack st;
    MyQueue mq;
    return 0;
}
```

**讲解**：

- `Stack` 申请了堆空间，因此必须显式编写析构函数释放资源。
- `MyQueue` 没有直接申请资源，其成员 `Stack` 会自动析构，因此可以不写析构函数。
- 即使 `MyQueue` 显式写了空析构函数，它的两个 `Stack` 成员仍会调用 `~Stack()`。
- 对象析构顺序与构造顺序相反：后定义的对象先析构。

### 3.2 使用析构函数简化括号匹配

```cpp
#include<iostream>
using namespace std;
// 用最新加了构造和析构的C++版本Stack实现
bool isValid(const char* s) {
    Stack st;
    while (*s)
    {
        if (*s == '[' || *s == '(' || *s == '{')
        {
            st.Push(*s);
        }
        else
        {
            // 右括号比左括号多，数量匹配问题
            if (st.Empty())
            {
                return false;
            }
            // 栈里面取左括号
            char top = st.Top();
            st.Pop();
            // 顺序不匹配
            if ((*s == ']' && top != '[')
                || (*s == '}' && top != '{')
                || (*s == ')' && top != '('))
            {
                return false;
            }
        }
        ++s;
    }
    // 栈为空，返回真，说明数量都匹配  左括号多，右括号少匹配问题
    return st.Empty();
}
```

```cpp
// 用之前C版本Stack实现
bool isValid(const char* s) {
    ST st;
    STInit(&st);
    while (*s)
    {
        // 左括号入栈
        if (*s == '(' || *s == '[' || *s == '{')
        {
            STPush(&st, *s);
        }
        else // 右括号取栈顶左括号尝试匹配
        {
            if (STEmpty(&st))
            {
                STDestroy(&st);
                return false;
            }
            char top = STTop(&st);
            STPop(&st);
            // 不匹配
            if ((top == '(' && *s != ')')
                || (top == '{' && *s != '}')
                || (top == '[' && *s != ']'))
            {
                STDestroy(&st);
                return false;
            }
        }
        ++s;
    }
    // 栈不为空，说明左括号比右括号多，数量不匹配
    bool ret = STEmpty(&st);
    STDestroy(&st);
    return ret;
}
int main()
{
    cout << isValid("[()][]") << endl;
    cout << isValid("[(])[]") << endl;
    return 0;
}
```

**讲解**：

- C++ 版本中 `Stack st;` 自动构造，函数返回前自动析构。
- C 版本必须在每个 `return` 前记得调用 `STDestroy`，容易遗漏。
- 这种“资源获取即初始化”的管理方式称为 RAII，是构造函数和析构函数的重要价值。

## 4. 拷贝构造函数

如果构造函数的第一个参数是自身类类型的引用，且其他参数都有默认值，则它是拷贝构造函数。

特点：

1. 拷贝构造是构造函数的一种重载。
2. 参数必须是类类型引用；使用传值会导致无限递归。
3. 自定义类型对象发生拷贝时必须调用拷贝构造，包括传值传参和传值返回。
4. 编译器默认生成的拷贝构造：
   - 对内置类型成员进行值拷贝，即浅拷贝。
   - 对自定义类型成员调用其拷贝构造。
5. `Date` 这类只有内置类型且不管理资源的类可以直接使用默认拷贝构造。
6. `Stack` 这类管理资源的类需要自己实现深拷贝。
7. `MyQueue` 主要由 `Stack` 成员组成，编译器生成的拷贝构造会调用 `Stack` 的深拷贝。
8. 返回局部对象的引用会产生野引用，不能使用。

### 4.1 Date 的拷贝构造

```cpp
#include<iostream>
using namespace std;
class Date
{
public:
    Date(int year = 1, int month = 1, int day = 1)
    {
        _year = year;
        _month = month;
        _day = day;
    }
    // 编译报错：error C2652: "Date": 非法的复制构造函数: 第一个参数不应是"Date"
    //Date(Date d)
    Date(const Date& d)
    {
        _year = d._year;
        _month = d._month;
        _day = d._day;
    }
    Date(Date* d)
    {
        _year = d->_year;
        _month = d->_month;
        _day = d->_day;
    }
    void Print()
    {
        cout << _year << "-" << _month << "-" << _day << endl;
    }
private:
    int _year;
    int _month;
    int _day;
};
void Func1(Date d)
{
    cout << &d << endl;
    d.Print();
}
// Date Func2()
Date& Func2()
{
    Date tmp(2024, 7, 5);
    tmp.Print();
    return tmp;
}
int main()
{
    Date d1(2024, 7, 5);
    // C++规定自定义类型对象进行拷贝行为必须调用拷贝构造，所以这里传值传参要调用拷贝构造
    // 所以这里的d1传值传参给d要调用拷贝构造完成拷贝，传引用传参可以较少这里的拷贝
    Func1(d1);
    cout << &d1 << endl;
    // 这里可以完成拷贝，但是不是拷贝构造，只是一个普通的构造
    Date d2(&d1);
    d1.Print();
    d2.Print();
    //这样写才是拷贝构造，通过同类型的对象初始化构造，而不是指针
    Date d3(d1);
    d2.Print();
    // 也可以这样写，这里也是拷贝构造
    Date d4 = d1;
    d2.Print();

    // Func2返回了一个局部对象tmp的引用作为返回值
    // Func2函数结束，tmp对象就销毁了，相当于了一个野引用
    Date ret = Func2();
    ret.Print();

    return 0;
}
```

**讲解**：

- `Date(Date d)` 不合法：传值形参本身需要拷贝，会递归调用拷贝构造。
- `Date(Date* d)` 只是普通构造函数，参数是指针，不是拷贝构造函数。
- `Date d2(&d1)` 调用的是 `Date(Date* d)`。
- `Date d3(d1)` 和 `Date d4 = d1` 才调用拷贝构造。
- `Date& Func2()` 返回局部对象 `tmp` 的引用，函数结束后 `tmp` 已销毁，会产生野引用。

### 4.2 Stack 的深拷贝

```cpp
#include<iostream>
using namespace std;
typedef int STDataType;
class Stack
{
public:
    Stack(int n = 4)
    {
        _a = (STDataType*)malloc(sizeof(STDataType) * n);
        if (nullptr == _a)
        {
            perror("malloc申请空间失败");
            return;
        }
        _capacity = n;
        _top = 0;
    }
    Stack(const Stack& st)
    {
        // 需要对_a指向资源创建同样大的资源再拷贝值
        _a = (STDataType*)malloc(sizeof(STDataType) * st._capacity);
        if (nullptr == _a)
        {
            perror("malloc申请空间失败!!!");
            return;
        }
        memcpy(_a, st._a, sizeof(STDataType) * st._top);
        _top = st._top;
        _capacity = st._capacity;
    }
    void Push(STDataType x)
    {
        if (_top == _capacity)
        {
            int newcapacity = _capacity * 2;
            STDataType* tmp = (STDataType*)realloc(_a, newcapacity * sizeof(STDataType));
            if (tmp == NULL)
            {
                perror("realloc fail");
                return;
            }
            _a = tmp;
            _capacity = newcapacity;
        }
        _a[_top++] = x;
    }
    ~Stack()
    {
        cout << "~Stack()" << endl;
        free(_a);
        _a = nullptr;
        _top = _capacity = 0;
    }
private:
    STDataType* _a;
    size_t _capacity;
    size_t _top;
};
// 两个Stack实现队列
class MyQueue
{
public:
private:
    Stack pushst;
    Stack popst;
};
int main()
{
    Stack st1;
    st1.Push(1);
    st1.Push(2);
    // Stack不显示实现拷贝构造，用自动生成的拷贝构造完成浅拷贝
    // 会导致st1和st2里面的_a指针指向同一块资源，析构时会析构两次，程序崩溃
    Stack st2 = st1;
    MyQueue mq1;
    // MyQueue自动生成的拷贝构造，会自动调用Stack拷贝构造完成pushst/popst
    // 的拷贝，只要Stack拷贝构造自己实现了深拷贝，他就没问题
    MyQueue mq2 = mq1;
    return 0;
}
```

**讲解**：

- 浅拷贝只复制 `_a` 指针本身，两个对象会指向同一块堆空间。
- 两个对象析构时会重复 `free` 同一块空间，导致程序崩溃。
- 深拷贝需要为新对象重新申请资源，并复制有效数据。
- `MyQueue` 自动生成的拷贝构造会调用每个 `Stack` 成员的深拷贝。

### 4.3 拷贝行为对比

| 类 | 成员特点 | 默认拷贝是否可用 |
| --- | --- | --- |
| `Date` | 全部为内置类型，不管理资源 | 可用，默认浅拷贝即可 |
| `Stack` | 有指针指向堆资源 | 不可用，必须自己实现深拷贝 |
| `MyQueue` | 主要由自定义类型 `Stack` 组成 | 可用，因为会自动调用 `Stack` 的深拷贝 |

## 5. 赋值运算符重载

### 5.1 运算符重载

运算符重载是为类类型对象指定运算符的新含义。

核心规则：

- 重载函数名为 `operator` 加运算符。
- 参数个数等于运算符操作对象数量。
- 作为成员函数时，第一个操作对象由隐式 `this` 传递，因此参数少一个。
- 重载后优先级和结合性不变。
- 不能创造新运算符。
- 以下 5 个运算符不能重载：`. .* :: sizeof ?:`
- 重载函数至少有一个类类型参数，不能改变内置类型的运算含义。
- 前置 `++` 和后置 `++` 通过后置版本的额外 `int` 参数区分。
- 输入输出运算符通常重载为全局函数，因为成员函数会迫使写法变成 `对象 << cout`。

#### 不能重载内置类型运算符

```cpp
#include<iostream>
using namespace std;
// 编译报错："operator +"必须至少有一个类类型的形参
int operator+(int x, int y)
{
   return x - y;
}
class A
{
public:
   void func()
   {
       cout << "A::func()" << endl;
   }
};
typedef void(A::*PF)(); //成员函数指针类型
int main()
{
   // C++规定成员函数要加&才能取到函数指针
   PF pf = &A::func;
   A obj;//定义ob类对象temp
   // 对象调用成员函数指针时，使用.*运算符
   (obj.*pf)();
   return 0;
}
```

**讲解**：`int operator+(int, int)` 试图改变内置类型 `int` 的加法，因此编译失败。成员函数指针通过 `.*` 调用，`.*` 不能被重载。

#### 全局函数实现 `operator==`

```cpp
#include<iostream>
using namespace std;
class Date
{
public:
   Date(int year = 1, int month = 1, int day = 1)
   {
       _year = year;
       _month = month;
       _day = day;
   }
   void Print()
   {
       cout << _year << "-" << _month << "-" << _day << endl;
   }
//private:
   int _year;
   int _month;
   int _day;
};
// 重载为全局的面临对象访问私有成员变量的问题
// 有几种方法可以解决：
// 1、成员放公有
// 2、Date提供getxxx函数
// 3、友元函数
// 4、重载为成员函数
bool operator==(const Date& d1, const Date& d2)
{
    return d1._year == d2._year
        && d1._month == d2._month
        && d1._day == d2._day;
}
int main()
{
   Date d1(2024, 7, 5);
   Date d2(2024, 7, 6);
   // 运算符重载函数可以显示调用
   operator==(d1, d2);
   // 编译器会转换成 operator==(d1, d2);
   d1 == d2;
   return 0;
}
```

**讲解**：全局运算符重载通常无法访问 `private` 成员，可改为公有成员、提供 `get` 函数、使用友元，或者重载为成员函数。

#### 成员函数实现 `operator==` 和自增

```cpp
#include<iostream>
using namespace std;
class Date
{
public:
   Date(int year = 1, int month = 1, int day = 1)
   {
       _year = year;
       _month = month;
       _day = day;
   }
   void Print()
   {
       cout << _year << "-" << _month << "-" << _day << endl;
   }
   bool operator==(const Date& d)
   {
       return _year == d._year
           && _month == d._month
           && _day == d._day;
   }
   Date& operator++()
   {
       cout << "前置++" << endl;
       //...
       return *this;
   }
   Date operator++(int)
   {
       Date tmp;
       cout << "后置++" << endl;
       //...
       return tmp;
   }
private:
   int _year;
   int _month;
   int _day;
};
int main()
{
   Date d1(2024, 7, 5);
   Date d2(2024, 7, 6);
   // 运算符重载函数可以显示调用
   d1.operator==(d2);
   // 编译器会转换成 d1.operator==(d2);
   d1 == d2;
   // 编译器会转换成 d1.operator++();
   ++d1;
   // 编译器会转换成 d1.operator++(0);
   d1++;
   return 0;
}
```

**讲解**：

- 成员函数 `operator==` 只显式接收右侧对象，左侧对象由 `this` 提供。
- 前置 `++` 修改当前对象并返回当前对象的引用。
- 后置 `++` 的额外 `int` 参数仅用于区分，通常返回旧值。

### 5.2 赋值运算符重载

赋值运算符重载用于两个已经存在的对象之间赋值。

| 概念 | 发生场景 | 例子 |
| --- | --- | --- |
| 拷贝构造 | 用已有对象初始化正在创建的新对象 | `Date d4 = d1;` |
| 赋值重载 | 两个已存在对象之间赋值 | `d1 = d3;` |

要点：

1. 必须重载为成员函数。
2. 参数建议写成 `const 当前类类型&`。
3. 返回值建议写成当前类类型引用，以支持连续赋值。
4. 编译器默认生成的是逐成员浅拷贝。
5. 管理资源的类需要自己实现深拷贝。
6. 如果类显式写了析构函数并释放资源，通常也应显式实现拷贝构造和赋值运算符重载。

```cpp
class Date
{
public:
   Date(int year = 1, int month = 1, int day = 1)
   {
       _year = year;
       _month = month;
       _day = day;
   }
   Date(const Date& d)
   {
       cout << " Date(const Date& d)" << endl;
       _year = d._year;
       _month = d._month;
       _day = d._day;
   }
   // 传引用返回减少拷贝
   // d1 = d2;
   Date& operator=(const Date& d)
   {
       // 不要检查自己给自己赋值的情况
       if (this != &d)
       {
           _year = d._year;
           _month = d._month;
           _day = d._day;
       }
       // d1 = d2表达式的返回对象应该为d1，也就是*this
       return *this;
   }
   void Print()
   {
       cout << _year << "-" << _month << "-" << _day << endl;
   }
private:
   int _year;
   int _month;
   int _day;
};
int main()
{
   Date d1(2024, 7, 5);
   Date d2(d1);
   Date d3(2024, 7, 6);
   d1 = d3;
   // 需要注意这里是拷贝构造，不是赋值重载
   // 请牢牢记住赋值重载完成两个已经存在的对象直接的拷贝赋值
   // 而拷贝构造用于一个对象拷贝初始化给另一个要创建的对象
   Date d4 = d1;
   return 0;
}
```

**讲解**：

- `d1 = d3` 调用 `operator=`。
- `Date d4 = d1` 是初始化，调用拷贝构造。
- `if (this != &d)` 用于检查自赋值。
- `return *this` 支持 `d1 = d2 = d3`。

## 6. 取地址运算符重载

### 6.1 const 成员函数

`const` 修饰成员函数时写在参数列表后面，实际修饰的是隐藏的 `this` 指针。

| 成员函数 | 隐藏 `this` 类型 |
| --- | --- |
| 普通成员函数 | `Date* const this` |
| `const` 成员函数 | `const Date* const this` |

```cpp
#include<iostream>
using namespace std;
class Date
{
public:
   Date(int year = 1, int month = 1, int day = 1)
   {
       _year = year;
       _month = month;
       _day = day;
   }
   // void Print(const Date* const this) const
   void Print() const
   {
       cout << _year << "-" << _month << "-" << _day << endl;
   }
private:
   int _year;
   int _month;
   int _day;
};
int main()
{
   // 这里非const对象也可以调用const成员函数是一种权限的缩小
   Date d1(2024, 7, 5);
   d1.Print();

   const Date d2(2024, 8, 5);
   d2.Print();
   return 0;
}
```

**讲解**：

- 非 `const` 对象可以调用 `const` 成员函数，权限缩小。
- `const` 对象不能调用非 `const` 成员函数，否则是权限放大。
- 只读函数应尽量声明为 `const`，使 `const` 对象也能使用。

### 6.2 取地址运算符重载

普通对象和 `const` 对象分别有对应的取地址重载：

#### [补充例题·力扣] 232. 用栈实现队列

出处：[LeetCode 232. 用栈实现队列](https://leetcode.cn/problems/implement-queue-using-stacks/)

题目：仅使用两个栈实现队列的 `push`、`pop`、`peek`、`empty`。

```cpp
#include <stack>
using namespace std;

class MyQueue {
public:
    MyQueue() = default;

    void push(int x) {
        inStack.push(x);
    }

    int pop() {
        moveInputToOutput();
        int value = outStack.top();
        outStack.pop();
        return value;
    }

    int peek() {
        moveInputToOutput();
        return outStack.top();
    }

    bool empty() {
        return inStack.empty() && outStack.empty();
    }

private:
    void moveInputToOutput() {
        if (outStack.empty()) {
            while (!inStack.empty()) {
                outStack.push(inStack.top());
                inStack.pop();
            }
        }
    }

    stack<int> inStack;
    stack<int> outStack;
};
```

复杂度：

- `push`：`O(1)`
- `pop`、`peek` 均摊：`O(1)`
- 空间：`O(n)`

**讲解**：`inStack` 只负责入队，`outStack` 只负责出队。出队时若 `outStack` 为空，则把 `inStack` 全部倒入 `outStack`，从而反转元素顺序。

#### [补充例题·牛客] BM43 包含 min 函数的栈

出处：[牛客 BM43 包含 min 函数的栈](https://www.nowcoder.com/practice/4c776177d2c04c2494f2555c9fcc1e49)

题目：实现支持 `push`、`pop`、`top`、`min` 的栈，各操作均为常数时间。

```cpp
#include <stack>
using namespace std;

class Solution {
public:
    void push(int value) {
        dataStack.push(value);
        if (minStack.empty() || value <= minStack.top()) {
            minStack.push(value);
        }
    }

    void pop() {
        if (dataStack.top() == minStack.top()) {
            minStack.pop();
        }
        dataStack.pop();
    }

    int top() {
        return dataStack.top();
    }

    int min() {
        return minStack.top();
    }

private:
    stack<int> dataStack;
    stack<int> minStack;
};
```

复杂度：

- 所有操作：`O(1)`
- 空间：`O(n)`

**讲解**：`dataStack` 保存所有元素，`minStack` 保存当前最小值。`push` 时只有新值不大于当前最小值才压入辅助栈。

| 主题 | 核心结论 |
| --- | --- |
| 默认构造函数 | 不传实参即可调用 |
