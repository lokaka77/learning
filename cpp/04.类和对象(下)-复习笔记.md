## 1. 再探构造函数

### 1.1 初始化列表

构造函数初始化成员有两种方式：

1. 函数体内赋值。
2. 初始化列表。

初始化列表从冒号开始，多个成员之间用逗号分隔：

```cpp
Date(int year, int month, int day)
    : _year(year)
    , _month(month)
    , _day(day)
{}
```

要点：

- 每个成员变量在初始化列表中只能出现一次。
- 可以认为初始化列表是每个成员真正初始化的位置。
- 引用成员、`const` 成员、没有默认构造的类类型成员必须使用初始化列表。
- C++11 支持在成员声明位置给缺省值，该值用于没有显式出现在初始化列表中的成员。
- 初始化顺序按成员在类中的声明顺序，与初始化列表书写顺序无关。
- 建议让声明顺序和初始化列表顺序保持一致。

```cpp
#include<iostream>
using namespace std;
class Time
{
public:
    Time(int hour)
        :_hour(hour)
    {
        cout << "Time()" << endl;
    }
private:
    int _hour;
};
class Date
{
public:
    Date(int& x, int year = 1, int month = 1, int day = 1)
        :_year(year)
        ,_month(month)
        ,_day(day)
        ,_t(12)
        ,_ref(x)
        ,_n(1)
    {
        // error C2512: "Time": 没有合适的默认构造函数可用
        // error C2530 : "Date::_ref" : 必须初始化引用
        // error C2789 : "Date::_n" : 必须初始化常量限定类型的对象
    }
    void Print() const
    {
        cout << _year << "-" << _month << "-" << _day << endl;
    }
private:
    int _year;
    int _month;
    int _day;
    Time _t;          // 没有默认构造
    int& _ref;          // 引用
    const int _n; // const
};
int main()
{
    int i = 0;
    Date d1(i);
    d1.Print();
    return 0;
}
```

**讲解**：

- `Time` 只有带参构造，没有默认构造，所以 `_t` 必须在初始化列表中初始化。
- 引用 `_ref` 必须在初始化列表中绑定。
- `const int _n` 必须在初始化列表中初始化。

### 1.2 C++11 成员声明位置缺省值

```cpp
#include<iostream>
using namespace std;
class Time
{
public:
    Time(int hour)
        :_hour(hour)
    {
        cout << "Time()" << endl;
    }
private:
    int _hour;
};
class Date
{
public:
    Date()
        :_month(2)
    {
        cout << "Date()" << endl;
    }
    void Print() const
    {
        cout << _year << "-" << _month << "-" << _day << endl;
    }
private:
    // 注意这里不是初始化，这里给的是缺省值，这个缺省值是给初始化列表的
    // 如果初始化列表没有显示初始化，默认就会用这个缺省值初始化
    int _year = 1;
    int _month = 1;
    int _day;
    Time _t = 1;
    const int _n = 1;
    int* _ptr = (int*)malloc(12);
};
int main()
{
    Date d1;
    d1.Print();
    return 0;
}
```

**讲解**：

- 成员声明位置的 `= 1` 不是直接赋值，而是缺省初始值。
- 如果初始化列表显式给出值，则使用初始化列表的值。
- 如果初始化列表没有给出，则使用缺省值。
- `_day` 没有缺省值，也没有在初始化列表中初始化，其值不确定。

### 1.3 初始化顺序选择题

下面程序的运行结果是什么？

A. 输出 1  1  
B. 输出 2  2  
C. 编译报错  
D. 输出 1  随机值  
E. 输出 1  2  
F. 输出 2  1

```cpp
#include<iostream>
using namespace std;
class A
{
public:
    A(int a)
        :_a1(a)
        , _a2(_a1)
    {}
    void Print() {
        cout << _a1 << " " << _a2 << endl;
    }
private:
    int _a2 = 2;
    int _a1 = 2;
};
int main()
{
    A aa(1);
    aa.Print();
}
```

**答案：D**

**讲解**：

- 成员声明顺序是 `_a2` 在前、`_a1` 在后。
- 因此初始化顺序是：先初始化 `_a2`，再初始化 `_a1`。
- `_a2(_a1)` 执行时，`_a1` 还没有初始化，读取到的是随机值。
- 随后 `_a1(a)` 把 `_a1` 初始化为 `1`。
- 最终输出 `1 随机值`。

## 2. 类型转换

C++ 允许内置类型隐式转换为类类型，前提是存在对应的构造函数。

在构造函数前加 `explicit`，可以禁止隐式类型转换。

```cpp
#include<iostream>
using namespace std;
class A
{
public:
    // 构造函数explicit就不再支持隐式类型转换
    // explicit A(int a1)
    A(int a1)
        :_a1(a1)
    {}
    //explicit A(int a1, int a2)
    A(int a1, int a2)
        :_a1(a1)
        ,_a2(a2)
    {}
    void Print()
    {
        cout << _a1 << " " << _a2 << endl;
    }
private:
    int _a1 = 1;
    int _a2 = 2;
};
int main()
{
    // 1构造一个A的临时对象，再用这个临时对象拷贝构造aa3
    // 编译器遇到连续构造+拷贝构造->优化为直接构造
    A aa1 = 1;
    aa1.Print();
    const A& aa2 = 1;
    // C++11之后才支持多参数转化
    A aa3 = { 2,2 };
    return 0;
}
```

**讲解**：

- `A aa1 = 1` 是隐式类型转换。
- `const A& aa2 = 1` 将临时对象绑定到 `const` 引用，临时对象生命周期被延长。
- `A aa3 = {2, 2}` 是多参数隐式转换，C++11 后才支持。
- 加 `explicit` 后只能使用 `A aa1(1)` 这种直接初始化。

## 3. static 成员

### 3.1 static 成员变量

要点：

- 静态成员变量必须类内声明、类外定义并初始化。
- 静态成员变量由所有对象共享，不属于某个对象。
- 静态成员变量不在对象中，存放在静态区。
- 静态成员变量受访问限定符限制。
- 静态成员变量不能在声明位置使用普通成员缺省值方式初始化。

### 3.2 static 成员函数

要点：

- 静态成员函数没有 `this` 指针。
- 可以访问静态成员，不能直接访问非静态成员。
- 非静态成员函数可以访问静态成员。
- 可以通过 `类名::静态成员` 或 `对象.静态成员` 访问。

### 3.3 统计当前对象数量

```cpp
// 实现一个类，计算程序中创建出了多少个类对象？
#include<iostream>
using namespace std;
class A
{
public:
    A()
    {
        ++_scount;
    }
    A(const A& t)
    {
        ++_scount;
    }
    ~A()
    {
        --_scount;
    }
    static int GetACount()
    {
        return _scount;
    }
private:
    // 类里面声明
    static int _scount;
};
// 类外面初始化
int A::_scount = 0;
int main()
{
    cout << A::GetACount() << endl;
    A a1, a2;
    A a3(a1);
    cout << A::GetACount() << endl;
    cout << a1.GetACount() << endl;
    // 编译报错：error C2248: "A::_scount": 无法访问 private 成员(在"A"类中声明)
    //cout << A::_scount << endl;
    return 0;
}
```

**讲解**：

- 构造和拷贝构造中增加计数，析构中减少计数。
- `_scount` 是 `private`，类外只能通过 `GetACount` 访问。
- `A::GetACount()` 和 `a1.GetACount()` 都能调用静态成员函数。

### 3.4 牛客原题：求 1+2+3+...+n

出处：[牛客 JZ64 求1+2+3+...+n](https://www.nowcoder.com/practice/7a0da8fc483247ff8800059e12d7caf1)

#### 使用外部类与静态成员

```cpp
class Sum
{
public:
    Sum()
    {
        _ret += _i;
        ++_i;
    }
    static int GetRet()
    {
        return _ret;
    }
private:
    static int _i;
    static int _ret;
};
int Sum::_i = 1;
int Sum::_ret = 0;
class Solution {
public:
    int Sum_Solution(int n) {
        // 变长数组
        Sum arr[n];
        return Sum::GetRet();
    }
};
```

**讲解**：每创建一个 `Sum` 对象，构造函数就累加一次。创建 `n` 个 `Sum` 对象即可完成 `1+...+n`，从而规避使用循环、条件判断等语法。

### 3.5 static 对象构造与析构选择题

设已经有 A、B、C、D 四个类的定义，程序中构造和析构顺序分别是什么？

构造选项：

A. D B A C  
B. B A D C  
C. C D B A  
D. A B D C  
E. C A B D  
F. C D A B

析构选项：

A. D B A C  
B. B A D C  
C. C D B A  
D. A B D C  
E. C A B D  
F. C D A B

```cpp
C c;
int main()
{
    A a;
    B b;
    static D d;
    return 0;
}
```

**答案**：

- 构造顺序：`E. C A B D`
- 析构顺序：`A. D B A C`

**讲解**：

- 全局对象 `c` 在 `main` 前构造。
- `main` 中先构造局部对象 `a`、`b`。
- 程序执行到 `static D d;` 时构造静态局部对象 `d`。
- 函数结束时，局部对象和静态局部对象按构造顺序的逆序析构：`d -> b -> a`。
- 全局对象 `c` 最后析构。

## 4. 友元

友元可以突破类的访问限定符。分为友元函数和友元类。

要点：

- 友元函数不是类成员函数。
- 友元声明可以放在类的任意访问区域。
- 一个函数可以是多个类的友元。
- 友元类中的所有成员函数可以访问另一个类的私有成员。
- 友元关系单向，不具有交换性。
- 友元关系不能传递。
- 友元会增加耦合，破坏封装，不宜多用。

### 4.1 友元函数

```cpp
#include<iostream>
using namespace std;
// 前置声明，都则A的友元函数声明编译器不认识B
class B;
class A
{
    // 友元声明
    friend void func(const A& aa, const B& bb);
private:
    int _a1 = 1;
    int _a2 = 2;
};
class B
{
    // 友元声明
    friend void func(const A& aa, const B& bb);
private:
    int _b1 = 3;
    int _b2 = 4;
};
void func(const A& aa, const B& bb)
{
    cout << aa._a1 << endl;
    cout << bb._b1 << endl;
}
int main()
{
    A aa;
    B bb;
    func(aa, bb);
    return 0;
}
```

**讲解**：`func` 同时在 `A` 和 `B` 中声明为友元，因此可以访问两个类的私有成员。

### 4.2 友元类

```cpp
#include<iostream>
using namespace std;
class A
{
    // 友元声明
    friend class B;
private:
    int _a1 = 1;
    int _a2 = 2;
};
class B
{
public:
    void func1(const A& aa)
    {
        cout << aa._a1 << endl;
        cout << _b1 << endl;
    }
    void func2(const A& aa)
    {
        cout << aa._a2 << endl;
        cout << _b2 << endl;
    }
private:
    int _b1 = 3;
    int _b2 = 4;
};
int main()
{
    A aa;
    B bb;
    bb.func1(aa);
    bb.func1(aa);
    return 0;
}
```

**讲解**：`B` 是 `A` 的友元类，所以 `B` 的所有成员函数都能访问 `A` 的私有成员。但 `A` 不是 `B` 的友元。

## 5. 内部类

一个类定义在另一个类内部，称为内部类。

要点：

- 内部类是独立类。
- 内部类受外部类类域和访问限定符限制。
- 外部类对象中不包含内部类对象。
- 内部类默认是外部类的友元。
- 适合表达两个类紧密关联的场景。

```cpp
#include<iostream>
using namespace std;
class A
{
private:
    static int _k;
    int _h = 1;
public:
    class B // B默认就是A的友元
    {
    public:
        void foo(const A& a)
        {
            cout << _k << endl;                //OK
            cout << a._h << endl;        //OK
        }
    };
};
int A::_k = 1;
int main()
{
    cout << sizeof(A) << endl;
    A::B b;
    A aa;
    b.foo(aa);
    return 0;
}
```

**讲解**：

- `sizeof(A)` 只计算 `A` 的成员，不包含内部类 `B`。
- `A::B b;` 需要通过外部类作用域访问内部类。
- `B` 是 `A` 的友元，可以访问 `A` 的私有成员。

### 5.1 使用内部类实现求和

```cpp
class Solution {
    // 内部类
    class Sum
    {
    public:
        Sum()
        {
            _ret += _i;
            ++_i;
        }
    };
    static int _i;
    static int _ret;
public:
    int Sum_Solution(int n) {
        // 变长数组
        Sum arr[n];
        return _ret;
    }
};
int Solution::_i = 1;
int Solution::_ret = 0;
```

**讲解**：`Sum` 是 `Solution` 的私有内部类，只能在 `Solution` 内部使用。通过构造 `n` 个对象完成累加。

## 6. 匿名对象

使用 `类型(实参)` 定义的对象称为匿名对象。

特点：

- 不需要名字。
- 生命周期只持续当前行，下一行自动析构。
- 适合临时调用某个成员函数。

```cpp
class A
{
public:
    A(int a = 0)
        :_a(a)
    {
        cout << "A(int a)" << endl;
    }
    ~A()
    {
        cout << "~A()" << endl;
    }
private:
    int _a;
};
class Solution {
public:
    int Sum_Solution(int n) {
        //...
        return n;
    }
};
int main()
{
    A aa1;
    // 不能这么定义对象，因为编译器无法识别下面是一个函数声明，还是对象定义
    //A aa1();
    // 但是我们可以这么定义匿名对象，匿名对象的特点不用取名字，
    // 但是他的生命周期只有这一行，我们可以看到下一行他就会自动调用析构函数
    A();
    A(1);
    A aa2(2);
    // 匿名对象在这样场景下就很好用，当然还有一些其他使用场景，这个我们以后遇到了再说
    Solution().Sum_Solution(10);
    return 0;
}
```

**讲解**：

- `A aa1();` 会被解释为函数声明，不是对象定义。
- `A()` 和 `A(1)` 是匿名对象，当前行结束后析构。
- `Solution().Sum_Solution(10)` 临时创建对象并立即调用成员函数。

## 7. 对象拷贝时的编译器优化

现代编译器会在不影响正确性的前提下减少不必要的拷贝。

常见优化：

- 连续构造 + 拷贝构造可能合并为一次构造。
- 传值传参可能省略临时对象拷贝。
- 返回值优化可能省略返回对象拷贝。
- 优化细节由编译器和 C++ 标准版本决定。

```cpp
#include<iostream>
using namespace std;
class A
{
public:
    A(int a = 0)
        :_a1(a)
    {
        cout << "A(int a)" << endl;
    }
    A(const A& aa)
        :_a1(aa._a1)
    {
        cout << "A(const A& aa)" << endl;
    }
    A& operator=(const A& aa)
    {
        cout << "A& operator=(const A& aa)" << endl;
        if (this != &aa)
        {
            _a1 = aa._a1;
        }
        return *this;
    }
    ~A()
    {
        cout << "~A()" << endl;
    }
private:
    int _a1 = 1;
};
void f1(A aa)
{}
A f2()
{
    A aa;
    return aa;
}
int main()
{
    // 传值传参
    A aa1;
    f1(aa1);
    cout << endl;
    // 隐式类型，连续构造+拷贝构造->优化为直接构造
    f1(1);
    // 一个表达式中，连续构造+拷贝构造->优化为一个构造
    f1(A(2));
    cout << endl;
    cout << "***********************************************" << endl;
    // 传值返回
    // 返回时一个表达式中，连续拷贝构造+拷贝构造->优化一个拷贝构造 （vs2019）
    // 一些编译器会优化得更厉害，进行跨行合并优化，直接变为构造。（vs2022）
    f2();
    cout << endl;
    // 返回时一个表达式中，连续拷贝构造+拷贝构造->优化一个拷贝构造 （vs2019）
    // 一些编译器会优化得更厉害，进行跨行合并优化，直接变为构造。（vs2022）
    A aa2 = f2();
    cout << endl;
    // 一个表达式中，连续拷贝构造+赋值重载->无法优化
    aa1 = f2();
    cout << endl;
    return 0;
}
```

**讲解**：

- `f1(1)` 隐式构造临时对象，传参时可能直接构造形参。
- `f1(A(2))` 可能把连续构造和拷贝构造优化为一次构造。
- `A aa2 = f2()` 可能触发返回值优化。
- `aa1 = f2()` 最终仍要调用赋值运算符重载，不能完全省略赋值。
- 不同编译器输出可能不同，不应依赖具体优化次数。

### [补充例题·力扣] 622. 设计循环队列

出处：[LeetCode 622. 设计循环队列](https://leetcode.cn/problems/design-circular-queue/)

题目：设计一个固定容量且支持循环使用的队列。

```cpp
#include <vector>
using namespace std;

class MyCircularQueue {
public:
    MyCircularQueue(int k)
        : data_(k), head_(0), tail_(0), size_(0), capacity_(k) {}

    bool enQueue(int value) {
        if (isFull()) {
            return false;
        }
        data_[tail_] = value;
        tail_ = (tail_ + 1) % capacity_;
        ++size_;
        return true;
    }

    bool deQueue() {
        if (isEmpty()) {
            return false;
        }
        head_ = (head_ + 1) % capacity_;
        --size_;
        return true;
    }

    int Front() {
        return isEmpty() ? -1 : data_[head_];
    }

    int Rear() {
        return isEmpty() ? -1 : data_[(tail_ + capacity_ - 1) % capacity_];
    }

    bool isEmpty() {
        return size_ == 0;
    }

    bool isFull() {
        return size_ == capacity_;
    }

private:
    vector<int> data_;
    int head_;
    int tail_;
    int size_;
    int capacity_;
};
```

复杂度：

- 所有操作：`O(1)`
- 空间：`O(k)`

**讲解**：使用数组保存元素，通过取模实现循环下标。`size_` 用于区分队空和队满。构造时通过初始化列表初始化成员变量。

### [补充例题·力扣] 707. 设计链表

出处：[LeetCode 707. 设计链表](https://leetcode.cn/problems/design-linked-list/)

题目：设计单链表，支持获取、头插、尾插、指定下标插入和删除。

```cpp
class MyLinkedList {
public:
    MyLinkedList() : head_(nullptr), size_(0) {}

    ~MyLinkedList() {
        Node* cur = head_;
        while (cur != nullptr) {
            Node* next = cur->next;
            delete cur;
            cur = next;
        }
    }

    int get(int index) {
        if (index < 0 || index >= size_) {
            return -1;
        }
        Node* cur = head_;
        while (index--) {
            cur = cur->next;
        }
        return cur->val;
    }

    void addAtHead(int val) {
        addAtIndex(0, val);
    }

    void addAtTail(int val) {
        addAtIndex(size_, val);
    }

    void addAtIndex(int index, int val) {
        if (index < 0 || index > size_) {
            return;
        }
        Node* node = new Node(val);
        if (index == 0) {
            node->next = head_;
            head_ = node;
        } else {
            Node* cur = head_;
            while (--index) {
                cur = cur->next;
            }
            node->next = cur->next;
            cur->next = node;
        }
        ++size_;
    }

    void deleteAtIndex(int index) {
        if (index < 0 || index >= size_) {
            return;
        }
        Node* target = nullptr;
        if (index == 0) {
            target = head_;
            head_ = head_->next;
        } else {
            Node* cur = head_;
            while (--index) {
                cur = cur->next;
            }
            target = cur->next;
            cur->next = target->next;
        }
        delete target;
        --size_;
    }

private:
    struct Node {
        int val;
        Node* next;
        Node(int v) : val(v), next(nullptr) {}
    };

    Node* head_;
    int size_;
};
```

复杂度：

- `get`：`O(index)`
- 插入和删除：`O(index)`
- 空间：`O(n)`

**讲解**：链表不需要连续空间，插入删除只需修改指针。`Node` 是 `MyLinkedList` 的内部结构，正好练习内部类型和成员函数封装。

### [补充例题·牛客] JZ64 求1+2+3+...+n

出处：[牛客 JZ64 求1+2+3+...+n](https://www.nowcoder.com/practice/7a0da8fc483247ff8800059e12d7caf1)

题目要求不使用乘除法、循环、条件判断等关键字计算累加和。原课件中的两种构造对象解法已在前文保留，本题可重点练习：

1. 使用普通类和静态成员。
2. 使用内部类隐藏辅助类。

```cpp
class Solution {
private:
    class Sum {
    public:
        Sum() {
            ret += i;
            ++i;
        }
    };
    static int i;
    static int ret;

public:
    int Sum_Solution(int n) {
        i = 1;
        ret = 0;
        Sum arr[n];
        return ret;
    }
};

int Solution::i = 0;
int Solution::ret = 0;
```

复杂度：

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`

**讲解**：每次构造 `Sum` 对象时累加一次，创建 `n` 个对象即可计算总和。注意静态变量在多次调用前需要重置，避免跨测试用例残留状态。

### [补充例题·牛客] BM42 用两个栈实现队列

出处：[牛客 BM42 用两个栈实现队列](https://www.nowcoder.com/practice/54275ddae22f475981afa2244dd448c6)

```cpp
#include <stack>
using namespace std;

class Solution {
public:
    void push(int node) {
        stack1.push(node);
    }

    int pop() {
        if (stack2.empty()) {
            while (!stack1.empty()) {
                stack2.push(stack1.top());
                stack1.pop();
            }
        }
        int value = stack2.top();
        stack2.pop();
        return value;
    }

private:
    stack<int> stack1;
    stack<int> stack2;
};
```

复杂度：

- 插入均摊：`O(1)`
- 删除均摊：`O(1)`
- 空间：`O(n)`

**讲解**：这道题适合复习类成员封装和成员函数之间的协作，同时练习资源管理。

### 7.3 本章复习速查

| 主题 | 核心结论 |
| --- | --- |
| 初始化列表 | 引用、`const`、无默认构造的成员必须在这里初始化 |
| 初始化顺序 | 按成员声明顺序，不按初始化列表书写顺序 |
| 成员缺省值 | C++11 支持，初始化列表未显式给出时使用 |
| `explicit` | 禁止隐式类型转换 |
| 静态成员变量 | 类内声明，类外定义初始化，所有对象共享 |
| 静态成员函数 | 没有 `this`，只能访问静态成员 |
| 友元 | 可访问私有成员，但会破坏封装 |
| 内部类 | 独立类，默认是外部类友元 |
| 匿名对象 | 生命周期仅当前行 |
| 编译器优化 | 可能省略部分拷贝，具体行为不可依赖 |

4. 静态成员函数为什么不能访问普通成员变量？
5. 友元关系和内部类分别解决什么问题？
