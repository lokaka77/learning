## 1. 类的定义

### 1.1 类定义格式

基本格式：

```cpp
class 类名
{
public:
    // 对外提供的成员函数

private:
    // 内部成员变量

}; // 分号不能省略
```

要点：

- `class` 是定义类的关键字。
- 类体中的变量称为成员变量或属性。
- 类体中的函数称为成员函数或方法。
- 类定义结束后的分号不能省略。
- 成员变量通常加 `_`、`m` 等标识，这只是约定，不是语言强制要求。
- C++ 中 `struct` 也可以定义类，且 `struct` 中可以定义函数。
- 定义在类内的成员函数默认是 `inline`。

#### 示例 1：Stack 类

```cpp
#include<iostream>
using namespace std;
class Stack
{
public:
    // 成员函数
    void Init(int n = 4)
    {
        array = (int*)malloc(sizeof(int) * n);
        if (nullptr == array)
        {
            perror("malloc申请空间失败");
            return;
        }
        capacity = n;
        top = 0;
    }
    void Push(int x)
    {
        // ...扩容
        array[top++] = x;
    }
    int Top()
    {
        assert(top > 0);
        return array[top - 1];
    }
    void Destroy()
    {
        free(array);
        array = nullptr;
        top = capacity = 0;
    }
private:
    // 成员变量
    int* array;
    size_t capacity;
    size_t top;
}; // 分号不能省略

int main()
{
    Stack st;
    st.Init();
    st.Push(1);
    st.Push(2);
    cout << st.Top() << endl;
    st.Destroy();
    return 0;
}
```

**讲解**：

- `Init`、`Push`、`Top`、`Destroy` 是成员函数。
- `array`、`capacity`、`top` 是私有成员变量。
- `st` 是 `Stack` 实例化出的对象，通过 `st.Init()` 调用成员函数。
- 原示例中的 `Push` 只展示了入栈逻辑，扩容部分用注释省略；实际完整实现需要在容量不足时扩容。

#### 示例 2：成员变量命名习惯

```cpp
class Date
{
public:
    void Init(int year, int month, int day)
    {
        _year = year;
        _month = month;
        _day = day;
    }
private:
    // 为了区分成员变量，一般习惯上成员变量
    // 会加一个特殊标识，如_ 或者 m开头
    int _year; // year_  m_year
    int _month;
    int _day;
};

int main()
{
    Date d;
    d.Init(2024, 3, 31);
    return 0;
}
```

**讲解**：`_year`、`_month`、`_day` 使用下划线区分成员变量和普通局部变量。常见命名方式还有 `year_`、`m_year`。

#### 示例 3：C++ 中 struct 升级为类

```cpp
#include<iostream>
using namespace std;
// C++升级struct升级成了类
// 1、类里面可以定义函数
// 2、struct名称就可以代表类型
// C++兼容C中struct的用法
typedef struct ListNodeC
{
    struct ListNodeC* next;
    int val;
}LTNode;

// 不再需要typedef，ListNodeCPP就可以代表类型
struct ListNodeCPP
{
    void Init(int x)
    {
        next = nullptr;
        val = x;
    }
    ListNodeCPP* next;
    int val;
};

int main()
{
    return 0;
}
```

**讲解**：

- C 中 `struct ListNodeC` 必须加 `struct` 关键字，除非使用 `typedef`。
- C++ 中 `struct ListNodeCPP` 可以直接作为类型名使用。
- C++ 的 `struct` 中还可以定义成员函数。

### 1.2 访问限定符

C++ 通过访问限定符实现封装，选择性地向外部提供接口。

| 访问限定符 | 类外能否直接访问 | 说明 |
| --- | --- | --- |
| `public` | 可以 | 对外公开接口 |
| `protected` | 不可以 | 与 `private` 在本章作用相同，区别主要在继承中体现 |
| `private` | 不可以 | 内部实现细节 |

规则：

1. 访问权限从某个访问限定符出现的位置开始，直到下一个访问限定符或类结束。
2. `class` 未写访问限定符时默认 `private`。
3. `struct` 未写访问限定符时默认 `public`。
4. 成员变量通常设为 `private` 或 `protected`。
5. 外部需要调用的成员函数通常设为 `public`。

```cpp
class Example
{
    int a;          // class 默认 private
public:
    int b;          // public
private:
    int c;          // private
};
```

### 1.3 类域

类定义了一个新的作用域。在类外定义成员函数时，需要使用 `类名::成员名` 指明它属于哪个类。

```cpp
#include<iostream>
using namespace std;
class Stack
{
public:
    // 成员函数
    void Init(int n = 4);
private:
    // 成员变量
    int* array;
    size_t capacity;
    size_t top;
};
// 声明和定义分离，需要指定类域
void Stack::Init(int n)
{
    array = (int*)malloc(sizeof(int) * n);
    if (nullptr == array)
    {
        perror("malloc申请空间失败");
        return;
    }
    capacity = n;
    top = 0;
}
int main()
{
    Stack st;
    st.Init();
    return 0;
}
```

**讲解**：

- 如果不写 `Stack::`，编译器会把 `Init` 当成全局函数。
- 全局函数中找不到 `array`、`capacity`、`top`，因此编译报错。
- 写了 `Stack::Init` 后，函数体内找不到的名称会继续到 `Stack` 类域中查找。

## 2. 实例化

### 2.1 实例化概念

用类类型创建对象的过程称为实例化。

| 概念 | 类比 |
| --- | --- |
| 类 | 建筑设计图 |
| 对象 | 按照设计图建造出的房子 |

关键结论：

- 类中成员变量只是声明，不分配空间。
- 实例化对象时才分配实际物理空间。
- 一个类可以实例化出多个对象。
- 不同对象拥有各自独立的成员变量。

```cpp
#include<iostream>
using namespace std;
class Date
{
public:
    void Init(int year, int month, int day)
    {
        _year = year;
        _month = month;
        _day = day;
    }
    void Print()
    {
        cout << _year << "/" << _month << "/" << _day << endl;
    }
private:
    // 这里只是声明，没有开空间
    int _year;
    int _month;
    int _day;
};

int main()
{
    // Date类实例化出对象d1和d2
    Date d1;
    Date d2;

    d1.Init(2024, 3, 31);
    d1.Print();

    d2.Init(2024, 7, 5);
    d2.Print();
    return 0;
}
```

**讲解**：`d1` 和 `d2` 各自保存 `_year`、`_month`、`_day`。修改 `d1` 不会影响 `d2`。

### 2.2 对象大小

对象中只存储成员变量，不重复存储成员函数。

原因：

1. 成员函数编译后是指令，存放在代码段。
2. 同类型所有对象共用同一套成员函数。
3. 如果把函数指针存入每个对象，会重复占用空间。
4. 普通成员函数地址在编译链接阶段就可以确定，不需要在每个对象中保存。

对象大小遵循内存对齐规则：

1. 第一个成员在偏移量为 0 的位置。
2. 其他成员要对齐到“对齐数”的整数倍地址。
3. 对齐数等于编译器默认对齐数与成员自身大小的较小值。
4. VS 默认对齐数通常为 8。
5. 结构体总大小是最大对齐数的整数倍。
6. 嵌套结构体按自己的最大对齐数参与整体对齐计算。

```cpp
#include<iostream>
using namespace std;
// 计算一下A/B/C实例化的对象是多大？
class A
{
public:
    void Print()
    {
        cout << _ch << endl;
    }
private:
    char _ch;
    int _i;
};

class B
{
public:
    void Print()
    {
        //...
    }
};

class C
{};

int main()
{
    A a;
    B b;
    C c;
    cout << sizeof(a) << endl;
    cout << sizeof(b) << endl;
    cout << sizeof(c) << endl;
    return 0;
}
```

结果与推导：

| 类 | 成员 | 大小 | 说明 |
| --- | --- | --- | --- |
| `A` | `char _ch; int _i;` | `8` | `_ch` 占偏移 0，`_i` 对齐到偏移 4，总大小补齐为最大对齐数 4 的整数倍 |
| `B` | 无 | `1` | 空对象占 1 字节用于占位，表示对象存在 |
| `C` | 无 | `1` | 同 `B` |

**讲解**：空类大小通常为 1 字节。如果大小为 0，就无法区分不同对象的存在，因此编译器给 1 字节占位。

## 3. this 指针

成员函数如何知道当前调用的是 `d1` 还是 `d2`？

C++ 编译器会给成员函数在第一个形参位置隐式增加当前类类型指针：

```cpp
void Date::Init(Date* const this, int year, int month, int day)
```

要点：

- `this` 是指向当前对象的指针。
- 成员函数中直接写 `_year = year`，本质上等价于 `this->_year = year`。
- 用户不能在形参或实参中显式写 `this`。
- 函数体内可以显式使用 `this`。
- `this` 是 `类类型* const`，不能修改其指向。

```cpp
#include<iostream>
using namespace std;
class Date
{
public:
    // void Init(Date* const this, int year, int month, int day)
    void Init(int year, int month, int day)
    {
        // 编译报错：error C2106: "=": 左操作数必须为左值
        // this = nullptr;
        // this->_year = year;
        _year = year;
        this->_month = month;
        this->_day = day;
    }
    void Print()
    {
        cout << _year << "/" << _month << "/" << _day << endl;
    }
private:
    // 这里只是声明，没有开空间
    int _year;
    int _month;
    int _day;
};

int main()
{
    // Date类实例化出对象d1和d2
    Date d1;
    Date d2;

    // d1.Init(&d1, 2024, 3, 31);
    d1.Init(2024, 3, 31);
    d1.Print();

    d2.Init(2024, 7, 5);
    d2.Print();
    return 0;
}
```

**讲解**：

- 调用 `d1.Init(2024, 3, 31)` 时，编译器实际传入 `&d1` 作为隐藏的 `this`。
- 调用 `d2.Init(2024, 7, 5)` 时，隐藏参数是 `&d2`。
- `this = nullptr` 不允许，因为 `this` 本身是 `Date* const`。

### 3.1 this 指针选择题

#### 第 1 题

下面程序编译运行结果是：

A. 编译报错  
B. 运行崩溃  
C. 正常运行

```cpp
#include<iostream>
using namespace std;
class A
{
public:
    void Print()
    {
        cout << "A::Print()" << endl;
    }
private:
    int _a;
};

int main()
{
    A* p = nullptr;
    p->Print();
    return 0;
}
```

**答案：C**

**讲解**：`p->Print()` 实际上调用成员函数并传入 `this = nullptr`。这个 `Print` 没有访问任何成员变量，只输出字符串，因此在常见实现中不会解引用 `this`，程序可以正常运行。

> 严格来说，对空指针进行成员调用属于未定义行为，但从这道题考察的常规结果来看，应选择“正常运行”。

#### 第 2 题

下面程序编译运行结果是：

A. 编译报错  
B. 运行崩溃  
C. 正常运行

```cpp
#include<iostream>
using namespace std;
class A
{
public:
    void Print()
    {
        cout << "A::Print()" << endl;
        cout << _a << endl;
    }
private:
    int _a;
};

int main()
{
    A* p = nullptr;
    p->Print();
    return 0;
}
```

**答案：B**

**讲解**：`cout << _a` 等价于访问 `this->_a`。此时 `this` 是空指针，访问空指针指向的成员会导致运行崩溃。

#### 第 3 题

`this` 指针存放在内存的哪个区域？

A. 栈  
B. 堆  
C. 静态区  
D. 常量区  
E. 对象里面

**答案：A**

**讲解**：`this` 是成员函数的隐藏形参。普通函数形参通常位于栈上，因此 `this` 通常也存放在栈区。实际实现中也可能通过寄存器传递，但按本题选项应选“栈”。

## 4. C++和C语言实现Stack对比

面向对象三大特性：

```text
封装、继承、多态
```

通过 C 和 C++ 的 Stack 实现，可以初步理解封装。

### 4.1 C 实现 Stack

```c
#include<stdio.h>
#include<stdlib.h>
#include<stdbool.h>
#include<assert.h>
typedef int STDataType;
typedef struct Stack
{
    STDataType* a;
    int top;
    int capacity;
}ST;

void STInit(ST* ps)
{
    assert(ps);
    ps->a = NULL;
    ps->top = 0;
    ps->capacity = 0;
}

void STDestroy(ST* ps)
{
    assert(ps);
    free(ps->a);
    ps->a = NULL;
    ps->top = ps->capacity = 0;
}

void STPush(ST* ps, STDataType x)
{
    assert(ps);
    // 满了， 扩容
    if (ps->top == ps->capacity)
    {
        int newcapacity = ps->capacity == 0 ? 4 : ps->capacity * 2;
        STDataType* tmp = (STDataType*)realloc(ps->a, newcapacity * sizeof(STDataType));
        if (tmp == NULL)
        {
            perror("realloc fail");
            return;
        }
        ps->a = tmp;
        ps->capacity = newcapacity;
    }
    ps->a[ps->top] = x;
    ps->top++;
}

bool STEmpty(ST* ps)
{
    assert(ps);
    return ps->top == 0;
}

void STPop(ST* ps)
{
    assert(ps);
    assert(!STEmpty(ps));
    ps->top--;
}

STDataType STTop(ST* ps)
{
    assert(ps);
    assert(!STEmpty(ps));
    return ps->a[ps->top - 1];
}

int STSize(ST* ps)
{
    assert(ps);
    return ps->top;
}

int main()
{
    ST s;
    STInit(&s);
    STPush(&s, 1);
    STPush(&s, 2);
    STPush(&s, 3);
    STPush(&s, 4);
    while (!STEmpty(&s))
    {
        printf("%d\n", STTop(&s));
        STPop(&s);
    }
    STDestroy(&s);
    return 0;
}
```

### 4.2 C++ 实现 Stack

```cpp
#include<iostream>
using namespace std;
typedef int STDataType;
class Stack
{
public:
    // 成员函数
    void Init(int n = 4)
    {
        _a = (STDataType*)malloc(sizeof(STDataType) * n);
        if (nullptr == _a)
        {
            perror("malloc申请空间失败");
            return;
        }
        _capacity = n;
        _top = 0;
    }
    void Push(STDataType x)
    {
        if (_top == _capacity)
        {
            int newcapacity = _capacity * 2;
            STDataType* tmp = (STDataType*)realloc(_a, newcapacity * sizeof(STDataType));
            if (tmp == NULL)
            {
                perror("realloc fail");
                return;
            }
            _a = tmp;
            _capacity = newcapacity;
        }
        _a[_top++] = x;
    }
    void Pop()
    {
        assert(_top > 0);
        --_top;
    }
    bool Empty()
    {
        return _top == 0;
    }
    int Top()
    {
        assert(_top > 0);
        return _a[_top - 1];
    }
    void Destroy()
    {
        free(_a);
        _a = nullptr;
        _top = _capacity = 0;
    }
private:
    // 成员变量
    STDataType* _a;
    size_t _capacity;
    size_t _top;
};

int main()
{
    Stack s;
    s.Init();
    s.Push(1);
    s.Push(2);
    s.Push(3);
    s.Push(4);
    while (!s.Empty())
    {
        printf("%d\n", s.Top());
        s.Pop();
    }
    s.Destroy();
    return 0;
}
```

### 4.3 C 与 C++ 版本对比

| 比较项 | C 版本 | C++ 版本 |
| --- | --- | --- |
| 数据和操作 | 分离定义结构体和函数 | 数据与操作都放入类中 |
| 类型名 | 通常需要 `typedef` | 类名直接作为类型名 |
| 调用方式 | `STPush(&s, 1)` | `s.Push(1)` |
| 对象地址 | 需要显式传入 `&s` | 通过隐藏的 `this` 自动传递 |
| 数据保护 | 主要通过规范约束，成员仍可直接修改 | 可使用 `private` 限制外部访问 |
| 缺省参数 | 无 | 成员函数可使用缺省参数 |

底层数据和逻辑没有本质变化，但 C++ 把数据与操作绑定起来，并通过访问限定符进行更严格的管理，这就是封装的体现。

#### [补充例题·力扣] 155. 最小栈

出处：[LeetCode 155. 最小栈](https://leetcode.cn/problems/min-stack/)

题目：设计一个栈，支持 `push`、`pop`、`top`，并能在常数时间内获取最小值。

```cpp
#include <stack>
using namespace std;

class MinStack {
public:
    MinStack() = default;

    void push(int val) {
        data_.push(val);
        if (min_.empty() || val <= min_.top()) {
            min_.push(val);
        }
    }

    void pop() {
        if (data_.top() == min_.top()) {
            min_.pop();
        }
        data_.pop();
    }

    int top() {
        return data_.top();
    }

    int getMin() {
        return min_.top();
    }

private:
    stack<int> data_;
    stack<int> min_;
};
```

复杂度：

- 各操作时间复杂度：`O(1)`
- 额外空间复杂度：最坏 `O(n)`

**讲解**：使用两个栈。`data_` 保存全部元素，`min_` 保存当前最小值。只有新值小于或等于当前最小值时才同时压入 `min_`，弹出时同步维护即可。

#### [补充例题·力扣] 225. 用队列实现栈

出处：[LeetCode 225. 用队列实现栈](https://leetcode.cn/problems/implement-stack-using-queues/)

题目：仅使用队列的基本操作实现一个后进先出的栈。

```cpp
#include <queue>
using namespace std;

class MyStack {
public:
    MyStack() = default;

    void push(int x) {
        q_.push(x);
        int size = q_.size();
        while (size > 1) {
            q_.push(q_.front());
            q_.pop();
            --size;
        }
    }

    int pop() {
        int value = q_.front();
        q_.pop();
        return value;
    }

    int top() {
        return q_.front();
    }

    bool empty() {
        return q_.empty();
    }

private:
    queue<int> q_;
};
```

复杂度：

- `push` 时间复杂度：`O(n)`
- `pop`、`top`、`empty` 时间复杂度：`O(1)`
- 空间复杂度：`O(n)`

**讲解**：每压入一个元素，就把前面已有元素依次弹出并重新入队。这样队列头部始终保持最新入栈元素，从而模拟栈顶。

#### [补充例题·牛客] BM42 用两个栈实现队列

出处：[牛客 BM42 用两个栈实现队列](https://www.nowcoder.com/practice/54275ddae22f475981afa2244dd448c6)

题目：使用两个栈实现队列的 `push` 和 `pop`。

```cpp
#include <stack>
using namespace std;

class Solution {
public:
    void push(int node) {
        stack1.push(node);
    }

    int pop() {
        if (stack2.empty()) {
            while (!stack1.empty()) {
                stack2.push(stack1.top());
                stack1.pop();
            }
        }

        int value = stack2.top();
        stack2.pop();
        return value;
    }

private:
    stack<int> stack1;
    stack<int> stack2;
};
```

复杂度：

- 插入均摊时间复杂度：`O(1)`
- 删除均摊时间复杂度：`O(1)`
- 空间复杂度：`O(n)`

**讲解**：`stack1` 负责入队，`stack2` 负责出队。当 `stack2` 为空时，把 `stack1` 中的元素全部倒入 `stack2`，顺序即可反转。

#### [补充例题·牛客] BM43 包含 min 函数的栈

出处：[牛客 BM43 包含 min 函数的栈](https://www.nowcoder.com/practice/4c776177d2c04c2494f2555c9fcc1e49)

题目：实现一个能在常数时间内获得最小值的栈。

```cpp
#include <stack>
using namespace std;

class Solution {
public:
    void push(int value) {
        dataStack.push(value);
        if (minStack.empty() || value <= minStack.top()) {
            minStack.push(value);
        }
    }

    void pop() {
        if (dataStack.top() == minStack.top()) {
            minStack.pop();
        }
        dataStack.pop();
    }

    int top() {
        return dataStack.top();
    }

    int min() {
        return minStack.top();
    }

private:
    stack<int> dataStack;
    stack<int> minStack;
};
```

复杂度：

- 各操作时间复杂度：`O(1)`
- 空间复杂度：`O(n)`

**讲解**：与力扣最小栈思路一致。通过辅助栈维护历史最小值，使 `min` 操作不必遍历整个栈。
